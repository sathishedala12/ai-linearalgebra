01

The estimator API & canonical workflow

every model speaks the same dialect

Almost every object in sklearn is an estimator: it has .fit(). Predictive models add .predict(), transformers add .transform(), and many have .score(). Learning this contract is the single biggest unlock.

from sklearn.model_selection import train_test_split
from sklearn.preprocessing  import StandardScaler
from sklearn.ensemble       import RandomForestClassifier
from sklearn.metrics        import classification_report

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, stratify=y, random_state=42)

scaler = StandardScaler().fit(X_train)        # learn on TRAIN only
X_train_s = scaler.transform(X_train)
X_test_s  = scaler.transform(X_test)               # reuse the fitted scaler

model = RandomForestClassifier(n_estimators=300, random_state=42).fit(X_train_s, y_train)
y_pred = model.predict(X_test_s)
print(classification_report(y_test, y_pred))

The three verbs

  • fit(X, y) — learn parameters from training data.
  • predict(X) / predict_proba(X) — apply to new data.
  • transform(X) — for preprocessors; fit_transform() combines both on train.

Cross-validation splitters

from sklearn.model_selection import (
    KFold,             # vanilla k-fold
    StratifiedKFold,   # classification — preserve class ratios
    GroupKFold,        # prevent leakage across groups (e.g. user_id)
    TimeSeriesSplit,   # walk-forward, no future leakage
    RepeatedKFold,
)

Rule: never fit on the test set, never leak future into past, never split after SMOTE-ing.

Dimensionality reduction

decomposition · manifold 
from sklearn.decomposition import PCA, TruncatedSVD, NMF
from sklearn.manifold      import TSNE, Isomap

pca = PCA(n_components=0.95).fit(X_scaled)   # keep 95% variance
X_pca = pca.transform(X_scaled)
pca.explained_variance_ratio_.cumsum()

Choosing the tool

  • PCA — linear, fast, for compression & decorrelation.
  • TruncatedSVD — like PCA but for sparse matrices (tf-idf).
  • TSNE / UMAP — 2-D visualization only, never for downstream models.

Always scale before PCA.

Pipelines & ColumnTransformer

the cleanest way to ship a model

A Pipeline chains transformers and an estimator into one object. It prevents leakage (the scaler is fit on each CV fold's train split, not the whole data), and makes GridSearchCV tune preprocessing parameters too.

from sklearn.pipeline       import Pipeline
from sklearn.compose        import ColumnTransformer
from sklearn.preprocessing  import StandardScaler, OneHotEncoder
from sklearn.impute         import SimpleImputer
from sklearn.ensemble       import HistGradientBoostingClassifier

num_cols = ["age", "income", "tenure"]
cat_cols = ["country", "plan"]

num_pipe = Pipeline([
    ("impute", SimpleImputer(strategy="median")),
    ("scale",  StandardScaler()),
])
cat_pipe = Pipeline([
    ("impute", SimpleImputer(strategy="most_frequent")),
    ("ohe",    OneHotEncoder(handle_unknown="ignore", sparse_output=False)),
])

pre = ColumnTransformer([
    ("num", num_pipe, num_cols),
    ("cat", cat_pipe, cat_cols),
])

clf = Pipeline([
    ("pre",   pre),
    ("model", HistGradientBoostingClassifier(random_state=42)),
]).fit(X_tr, y_tr)

# Grid-search across preprocessing AND model
from sklearn.model_selection import GridSearchCV
grid = {
    "pre__num__impute__strategy": ["median", "mean"],
    "model__learning_rate":       [0.05, 0.1, 0.2],
    "model__max_iter":            [200, 400],
}
gs = GridSearchCV(clf, grid, cv=5, scoring="f1_macro", n_jobs=-1).fit(X_tr, y_tr)

# Persist the whole pipeline — preprocessing + model — as one artifact
import joblib
joblib.dump(gs.best_estimator_, "model.joblib")

Feature selection & importance

fewer features, less noise 
from sklearn.feature_selection import (
    SelectKBest, f_classif, mutual_info_classif,  # univariate
    VarianceThreshold,                            # drop near-constant
    RFE, RFECV,                                   # recursive elimination
    SelectFromModel,                              # keep top features from a model
)
from sklearn.inspection import permutation_importance

# 1. Drop low-variance noise
X2 = VarianceThreshold(threshold=0.01).fit_transform(X)

# 2. Univariate top-k
sel = SelectKBest(score_func=mutual_info_classif, k=20).fit(X, y)

# 3. Use a model's own importances
from sklearn.linear_model import LassoCV
sfm = SelectFromModel(LassoCV()).fit(X, y)

# 4. Permutation importance — model-agnostic, more reliable than .feature_importances_
result = permutation_importance(model, X_te, y_te, n_repeats=10, random_state=42)

Things people learn the hard way

leakage

Fit scalers, imputers, encoders, feature selectors inside a Pipeline. If you call fit_transform on the full dataset before splitting, your CV scores are lying.

imbalance

Accuracy is a trap when one class is rare. Use stratify=y, class_weight="balanced", PR-AUC, and StratifiedKFold. Resample only inside the pipeline (imbalanced-learn).

randomness

Set random_state=42 on splits, models, and CV. Without it, you can't tell whether your improvement is real or just a luckier seed.

scaling rules

Linear models, SVMs, KNN, PCA, NN — scale. Trees / forests / gradient boosting — don't bother. HistGBM even handles NaN natively.

starting point

Always run a dumb baseline first: DummyClassifier(strategy="most_frequent") or DummyRegressor(strategy="median"). If your fancy model can't beat it, stop and debug.

interpret

Reach for sklearn.inspection: permutation_importance, partial_dependence, PartialDependenceDisplay. They reveal what your model actually learned.
