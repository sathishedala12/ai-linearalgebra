📚 Advanced Features
1. Flexible Field Paths
Use nested paths as column headers: _nordstrom.event.channelBrand
2. Array Notation [] - Comma-Separated
Use [] in column header + comma-separated values:
Column: items[].skuId
Value: A001,A002,A003
Result: items: [{skuId:"A001"},{skuId:"A002"},{skuId:"A003"}]
Column: backInStockSKUs[]
Value: A001,A002,A003
Result: backInStockSKUs: ["A001","A002","A003"]
3. Object/Map Notation {} - Dynamic Keys
Use {} in column header + key=value;key=value pairs:
Column: priceDropSKUs{}
Value: A971531138=214.37|456.67;A416821464=171.85|172.90
Result: priceDropSKUs: {"A971531138":"214.37|456.67","A416821464":"171.85|172.90"}
⚠️ Use = between key/value, ; between entries
4. Timestamp Templates
Use {{timestamp}} or {{timestamp+N}}:
{{timestamp}} | {{timestamp+10}} | {{timestamp+20}}
Auto-increments +10s per event in batch/sequential mode
