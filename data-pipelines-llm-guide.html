Chapter 01

What is a Data Pipeline?

Plain English Analogy

A data pipeline is like a factory assembly line. Raw materials (messy data) come in one end. Each station cleans, shapes, or adds to the product. What comes out the other end is a finished good (clean, structured data ready for your LLM). Skip a station and you ship a broken product.

1.1 The Big Picture

Full Pipeline — Raw Data → LLM Output

┌─────────────────────────────────────────────────────────────────────┐ │ DATA PIPELINE FOR LLMs │ └─────────────────────────────────────────────────────────────────────┘ 📦 RAW SOURCES PDFs · CSVs · Databases · APIs · HTML · JSON · Logs · S3 │ ▼ 🧹 INGESTION Extract text, parse structure, handle encoding │ ▼ 🔍 VALIDATION Schema checks, null detection, duplicate flags │ ▼ 🧽 CLEANING Fix nulls, remove noise, normalize text, dedupe │ ▼ ⚙️ TRANSFORMATION Chunk, enrich, embed, tag, summarize │ ▼ 📐 FORMATTING Shape data into what the LLM expects │ ├──────────────────────┬──────────────────────┐ ▼ ▼ ▼ 🗄️ VectorDB Fine-tune Dataset Prompt Context (RAG pipeline) (JSONL training) (direct injection) │ │ │ └──────────────────────┴──────────────────────┘ │ ▼ 🤖 LLM generates answer

1.2 Types of Pipelines

Batch Pipeline

Processes data in scheduled runs. Nightly ETL jobs, weekly index rebuilds. Simple, predictable, good for most RAG setups.

  • Tools: Airflow, Prefect, cron
  • Latency: minutes to hours
  • Best for: documents, CSVs, archives

Streaming Pipeline

Processes events in real-time as they arrive. New support ticket → instantly indexed → LLM can answer about it within seconds.

  • Tools: Kafka, Flink, Kinesis
  • Latency: milliseconds to seconds
  • Best for: live data, events, logs

On-Demand Pipeline

Triggered by user action or API call. User uploads a PDF → pipeline runs immediately → LLM can answer about it.

  • Tools: FastAPI, Lambda, Cloud Run
  • Latency: seconds
  • Best for: user uploads, webhooks

Data Cleanup — Every Technique

⚠️

Garbage in, garbage out. An LLM trained or fed on dirty data will hallucinate, contradict itself, and give wrong answers. Cleaning is 80% of the work and 100% of the impact.

3.1 The Dirt Taxonomy

Structural

Missing columns, wrong dtypes, schema mismatches, malformed JSON, broken encoding.

Content

Null values, duplicates, contradictory records, stale/outdated info.

Text Noise

HTML tags, special chars, extra whitespace, headers/footers, boilerplate repeated text.

Semantic

Inconsistent terminology, abbreviations, different date formats, unit mismatches.

3.2 Text Cleaning — The Core Functions

python · text cleaning utilitiesimport re, unicodedata
from bs4 import BeautifulSoup

def clean_text(text: str) -> str:
    """Master text cleaner — run every chunk through this."""

    # 1. Remove HTML tags
    text = BeautifulSoup(text, "html.parser").get_text(separator=" ")

    # 2. Normalize unicode (ＡＢＣ → ABC, café → cafe)
    text = unicodedata.normalize("NFKD", text)
    text = text.encode("ascii", "ignore").decode("ascii")

    # 3. Remove boilerplate patterns
    text = re.sub(r"Page \d+ of \d+", "", text)          # PDF page numbers
    text = re.sub(r"CONFIDENTIAL|DRAFT|INTERNAL USE ONLY","",text,flags=re.I)

    # 4. Remove URLs (optional — keep if domain-relevant)
    text = re.sub(r"https?://\S+", "[URL]", text)

    # 5. Normalize whitespace
    text = re.sub(r"\n{3,}", "\n\n", text)    # max 2 blank lines
    text = re.sub(r"[ \t]{2,}", " ", text)    # collapse spaces/tabs
    text = re.sub(r"[^\S\n]+", " ", text)    # collapse non-newline whitespace

    # 6. Remove special chars (keep sentence punctuation)
    text = re.sub(r"[^\w\s\.\,\!\?\;\:\'\"\-\(\)\n]", "", text)

    # 7. Strip edges
    return text.strip()


# ── Remove repeated boilerplate across pages ──────────────
from collections import Counter

def remove_repeated_phrases(pages: list[str], threshold=0.7) -> list[str]:
    """Remove lines that appear in >70% of pages (headers/footers)."""
    all_lines = [line for page in pages for line in page.splitlines()]
    counts = Counter(l.strip() for l in all_lines if l.strip())
    boilerplate = {l for l, c in counts.items() if c / len(pages) > threshold}
    cleaned = []
    for page in pages:
        lines = [l for l in page.splitlines() if l.strip() not in boilerplate]
        cleaned.append("\n".join(lines))
    return cleaned

3.5 Near-Duplicate Detection

python · deduplication — MinHash + exact hashimport hashlib
from datasketch import MinHash, MinHashLSH

# ── Exact deduplication via content hash ─────────────────
def hash_text(text):
    return hashlib.md5(text.encode()).hexdigest()

seen = set()
unique_docs = []
for doc in documents:
    h = hash_text(doc.page_content)
    if h not in seen:
        seen.add(h)
        unique_docs.append(doc)

# ── Near-duplicate via MinHash LSH (80% similar = duplicate)
lsh = MinHashLSH(threshold=0.8, num_perm=128)
minhashes = {}

for i, doc in enumerate(documents):
    m = MinHash(num_perm=128)
    for word in doc.page_content.lower().split():
        m.update(word.encode())
    lsh.insert(f"doc_{i}", m)
    minhashes[f"doc_{i}"] = m

# Query: find near-duplicates of first doc
result = lsh.query(minhashes["doc_0"])
print("Near-duplicates:", result)

def normalize_for_llm(text: str) -> str:
    # Expand contractions
    contractions = {"don't":"do not","can't":"cannot","I'm":"I am"}
    for k, v in contractions.items():
        text = text.replace(k, v)

    # Standardize currency/numbers
    text = re.sub(r"\$\s*(\d+[\d,\.]*)", lambda m: m.group(0).replace(",",""), text)

    # Expand abbreviations
    abbrevs = {"e.g.":"for example","i.e.":"that is","etc.":"etcetera"}
    for k, v in abbrevs.items():
        text = text.replace(k, v)

    # Resolve coreference (basic: proper nouns)
    # Full coreference needs neuralcoref or spacy-experimental

    return text.strip()


def extract_entities(text: str) -> dict:
    """Extract structured metadata from unstructured text."""
    doc = nlp(text)
    return {
        "persons":       [e.text for e in doc.ents if e.label_ == "PERSON"],

def enrich_document(text: str, source: str, extra: dict = {}) -> Document:

Feeding Clean Data to the LLM

6.1 The Three Feeding Strategies

Direct Injection

Stuff cleaned data directly into the prompt context. Simple but limited by context window size. Best for small datasets or single records.

max ~200k tokens

RAG Retrieval

Index clean data into a vector database. Retrieve only the relevant chunks at query time. Scales to millions of documents.

unlimited scale

Fine-tuning

Train the model on your cleaned JSONL dataset. The knowledge becomes part of the weights. Expensive but gives best behavior.

permanent knowledge

6.2 Token Budget Management

python · fit data within context windowimport tiktoken

enc = tiktoken.encoding_for_model("gpt-4o")

def count_tokens(text: str) -> int:
    return len(enc.encode(text))

def truncate_to_budget(chunks: list[str], max_tokens=6000) -> str:
    """Greedily pack chunks until token budget is reached."""
    selected, total = [], 0
    for chunk in chunks:
        t = count_tokens(chunk)
        if total + t > max_tokens:
            break
        selected.append(chunk)
        total += t
    return "\n\n---\n\n".join(selected)

7.2 Full Fine-tune Data Pipeline Code

python · complete fine-tune pipelineimport pandas as pd, json, re
from sklearn.model_selection import train_test_split
import tiktoken

# ── Step 1: Load and clean ────────────────────────────────
df = pd.read_csv("support_tickets.csv")
df = df.dropna(subset=["question", "answer"])
df["question"] = df["question"].str.strip()
df["answer"]   = df["answer"].str.strip()

# ── Step 2: Quality filters ───────────────────────────────
df = df[df["question"].str.split().str.len() >= 5]   # min 5 words
df = df[df["answer"].str.split().str.len() >= 10]   # min 10 words answer
df = df.drop_duplicates(subset=["question"])

# ── Step 3: Build JSONL examples ─────────────────────────
SYSTEM = "You are a PayPal customer support specialist. Be helpful, accurate, and concise."
enc = tiktoken.encoding_for_model("gpt-4o")

def build_example(row) -> dict | None:
    msgs = [
        {"role":"system",    "content": SYSTEM},
        {"role":"user",      "content": row["question"]},
        {"role":"assistant", "content": row["answer"]},
    ]
    total_tokens = sum(len(enc.encode(m["content"])) for m in msgs)
    if total_tokens > 4096: return None  # skip too-long examples
    return {"messages": msgs}

examples = [r for _, row in df.iterrows() if (r:=build_example(row))]

# ── Step 4: Train/val/test split ──────────────────────────
train, temp  = train_test_split(examples, test_size=0.2, random_state=42)
val,   test  = train_test_split(temp,     test_size=0.5, random_state=42)

def write_jsonl(data, path):
    with open(path, "w") as f:
        for ex in data: f.write(json.dumps(ex) + "\n")

write_jsonl(train, "train.jsonl")
write_jsonl(val,   "val.jsonl")
write_jsonl(test,  "test.jsonl")
print(f"Train: {len(train)} | Val: {len(val)} | Test: {len(test)}")

# ── Step 5: Upload to OpenAI and start fine-tune ──────────
from openai import OpenAI
client = OpenAI()

train_file = client.files.create(open("train.jsonl","rb"), purpose="fine-tune")
val_file   = client.files.create(open("val.jsonl",  "rb"), purpose="fine-tune")

job = client.fine_tuning.jobs.create(
    training_file=train_file.id,
    validation_file=val_file.id,
    model="gpt-4o-mini-2024-07-18",
    hyperparameters={"n_epochs": 3}
)
print(f"Job ID: {job.id}")  # poll with client.fine_tuning.jobs.retrieve(job.id)

RAG Ingestion Pipeline

8.1 Production RAG Ingestion

python · complete rag ingestion pipelinefrom pathlib import Path
import hashlib, json, re
from langchain.document_loaders import PyPDFLoader, TextLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain.embeddings import OpenAIEmbeddings
from langchain.vectorstores import Qdrant
from qdrant_client import QdrantClient
from qdrant_client.models import Distance, VectorParams

# ── 1. Config ─────────────────────────────────────────────
CHUNK_SIZE    = 1000
CHUNK_OVERLAP = 200
EMBED_MODEL   = "text-embedding-3-small"
COLLECTION    = "paypal_knowledge"

# ── 2. Initialize Qdrant ──────────────────────────────────
client = QdrantClient("localhost", port=6333)
client.recreate_collection(
    collection_name=COLLECTION,
    vectors_config=VectorParams(size=1536, distance=Distance.COSINE)
)

# ── 3. Track processed files (incremental updates) ────────
def file_hash(path): return hashlib.md5(Path(path).read_bytes()).hexdigest()

processed = {}  # in prod: persist to Redis or SQLite

# ── 4. Ingestion function ─────────────────────────────────
embeddings = OpenAIEmbeddings(model=EMBED_MODEL)
splitter   = RecursiveCharacterTextSplitter(
    chunk_size=CHUNK_SIZE, chunk_overlap=CHUNK_OVERLAP
)

def ingest_file(path: str):
    fhash = file_hash(path)
    if processed.get(path) == fhash:
        print(f"Skipping (unchanged): {path}"); return

    # Load
    loader = PyPDFLoader(path) if path.endswith(".pdf") else TextLoader(path)
    raw_docs = loader.load()

    # Clean text
    for doc in raw_docs:
        doc.page_content = clean_text(doc.page_content)     # your clean_text()
        doc.page_content = re.sub(r"\n{3,}", "\n\n", doc.page_content)

    # Filter empty pages
    raw_docs = [d for d in raw_docs if len(d.page_content.split()) > 20]

    # Chunk
    chunks = splitter.split_documents(raw_docs)

    # Enrich metadata
    for i, chunk in enumerate(chunks):
        chunk.metadata["file_hash"]   = fhash
        chunk.metadata["chunk_index"] = i
        chunk.metadata["word_count"]  = len(chunk.page_content.split())

    # Embed + store
    Qdrant.from_documents(chunks, embeddings,
        url="http://localhost:6333", collection_name=COLLECTION)

    processed[path] = fhash
    print(f"Indexed {len(chunks)} chunks from {path}")

# ── 5. Run on a folder ────────────────────────────────────
for p in Path("./docs").rglob("*.pdf"):
    ingest_file(str(p))

10.2 Incremental Updates (Don't Re-index Everything)

python · incremental ingestion with change detectionimport sqlite3, hashlib
from pathlib import Path

# Track what's been indexed in SQLite
conn = sqlite3.connect("pipeline_state.db")
conn.execute("""CREATE TABLE IF NOT EXISTS indexed_files
    (path TEXT PRIMARY KEY, hash TEXT, indexed_at TEXT)""")

def needs_reindex(path: str) -> bool:
    current_hash = hashlib.md5(Path(path).read_bytes()).hexdigest()
    row = conn.execute(
        "SELECT hash FROM indexed_files WHERE path=?", (path,)
    ).fetchone()
    return not row or row[0] != current_hash

def mark_indexed(path: str):
    h = hashlib.md5(Path(path).read_bytes()).hexdigest()
    conn.execute("INSERT OR REPLACE INTO indexed_files VALUES (?,?,datetime('now'))",(path,h))
    conn.commit()

# Only re-index changed files
for p in Path("./docs").rglob("*"):
    if needs_reindex(str(p)):
        ingest_file(str(p))
        mark_indexed(str(p))

10.4 PII Redaction Before Feeding LLM

python · redact PII before sending to any cloud LLMimport re

def redact_pii(text: str) -> str:
    """Remove PII before sending to cloud LLM APIs."""

    # Emails
    text = re.sub(r"[\w\.-]+@[\w\.-]+\.\w+", "[EMAIL]", text)

    # Phone numbers (US format + international)
    text = re.sub(r"(\+?\d[\d\-\.\s]{7,}\d)", "[PHONE]", text)

    # SSN
    text = re.sub(r"\b\d{3}-\d{2}-\d{4}\b", "[SSN]", text)

    # Credit card numbers
    text = re.sub(r"\b(?:\d{4}[\s\-]?){3}\d{4}\b", "[CARD]", text)

    # IP addresses
    text = re.sub(r"\b(?:\d{1,3}\.){3}\d{1,3}\b", "[IP]", text)

    # Use spaCy NER for names (more accurate)
    import spacy
    nlp = spacy.load("en_core_web_sm")
    doc = nlp(text)
    for ent in reversed(doc.ents):  # reversed to preserve char offsets
        if ent.label_ in ["PERSON", "GPE"]:
            text = text[:ent.start_char] + f"[{ent.label_}]" + text[ent.end_char:]
    return text

10.5 Async Batch Embedding (10x Faster)

python · async parallel embedding for large datasetsimport asyncio, openai
from tenacity import retry, stop_after_attempt, wait_exponential

client = openai.AsyncOpenAI()

@retry(stop=stop_after_attempt(3), wait=wait_exponential(min=1, max=10))
async def embed_batch(texts: list[str]) -> list[list[float]]:
    """Embed a batch of texts with automatic retry on rate limit."""
    response = await client.embeddings.create(
        input=texts, model="text-embedding-3-small"
    )
    return [r.embedding for r in response.data]

async def embed_all(texts: list[str], batch_size=100) -> list[list[float]]:
    """Embed millions of texts in parallel batches."""
    batches = [texts[i:i+batch_size] for i in range(0, len(texts), batch_size)]
    tasks   = [embed_batch(b) for b in batches]
    results = await asyncio.gather(*tasks)
    return [vec for batch in results for vec in batch]

vectors = asyncio.run(embed_all(all_texts))
